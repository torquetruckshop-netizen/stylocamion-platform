# Stylo Camión Platform

Plataforma digital oficial de **Stylo Camión®**: portal, noticias, cargas, ventas, servicios y comunidad del transporte.

## Primera versión

La portada inicial incluye:

- Accesos a Stylo Cargas, Stylo Ventas y Noticias.
- Presentación de la Consultora y sus servicios.
- Espacio para Rodando Rafaela 2027.
- Contacto directo por WhatsApp.
- Diseño adaptable a teléfonos, tablets y computadoras.

## Archivos principales

- `index.html`: contenido y estructura.
- `styles.css`: identidad visual y diseño responsive.
- `app.js`: menú móvil y pequeñas interacciones.
